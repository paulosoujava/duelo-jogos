# Duelo!

Site de jogos para dois jogadores, cada um no seu celular: Jogo da Velha, Forca, Damas (regras brasileiras) e Dominó.

Um jogador cria a sala, manda o link e o outro entra. A conexão entre os celulares é direta (WebRTC via PeerJS), sem servidor próprio.

Site estático: basta publicar o `index.html` (Vercel, Netlify, GitHub Pages).
